MARMALADE LIBRARY — UNIVERSAL DIRECT DOWNLOAD

This branch is an installable ZIP, generated directly by GitHub.

To download: Use the branch's Code > Download ZIP command. Select the downloaded OUTER ZIP in Minternet > Extensions > Minternet > Import. Older Minternet importers find the root manifest.json inside GitHub's single top-level folder. Newer Minternet importers can also discover the nested browser variants.

The browsers/ folder contains five-file unpacked source packages for Chrome, Edge, Brave, Opera, Vivaldi, Minternet, Firefox and Safari. Firefox requires signing for permanent installation, and Safari requires Apple packaging/signing. Browser file-system permissions cannot be silently bypassed.

No media bytes are uploaded or backed up. Library catalog retention and permission to reopen files are separate capabilities.
